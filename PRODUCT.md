# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Hosts running a fast multiplayer activity and participants joining from desktop or mobile browsers. Spectators need a legible read-only broadcast view.

## Product Purpose

Code Premier League (CPL) is an unofficial educational simulation that turns a developer quiz and cricket squad auction into an energetic shared experience. Success means a host can create a room, participants can join with almost no setup, bids resolve consistently, and everyone can understand the final result.

## Positioning

CPL combines an authoritative live auction, developer knowledge bonuses, and a transparent deterministic squad score in one credential-free local flow.

## Operating Context

The host can share the console or spectator view while participants use personal devices. A typical session lasts 10-25 minutes and moves through registration, an optional five-question quiz, player auctions, squad review, and a published leaderboard.

## Capabilities and Constraints

- Local Mode must work without external credentials.
- Real player names, countries, and broad roles may be used descriptively from documented public sources.
- All prices, ratings, bids, and outcomes are simulated and must never be represented as official performance data or valuations.
- Player photographs, likenesses, copied biographies, team marks, board marks, and competition branding are excluded.
- The application must state that it is unofficial, educational, not endorsed, and intends no copyright or trademark infringement.
- No real-money flows, betting, wallets, or payments.
- DevCoins are stored as integers in the smallest display unit.
- Default rules: 50 DevCrore starting balance, 15 DevCrore quiz bonus cap, squad size 11, and maximum four overseas players.
- The MVP prioritizes deterministic behavior and recoverability over production durability.
- Realtime cloud persistence is an optional extension; the default implementation is authoritative within one running application process.

## Brand Commitments

The product name is Code Premier League (CPL). The experience should combine sports-broadcast urgency with developer-tool precision while remaining clearly unofficial, educational, friendly, and suitable for shared professional or community activities.

## Evidence on Hand

The player catalogue uses a dated, curated snapshot of names, countries, and broad roles from official cricket sources. No external image or logo assets are included.

## Product Principles

- Make the next action obvious under time pressure.
- Keep all scoring and bid decisions deterministic and explainable.
- Make mobile participation fast, forgiving, and touch-friendly.
- Treat auto-play status and simulated ratings as first-class trust signals.
- Prefer a complete local path over optional infrastructure.

## Accessibility & Inclusion

Controls must be keyboard accessible with visible focus, large mobile touch targets, high broadcast contrast, reduced-motion support, and live announcements for auction events. Awards remain celebratory and never humiliating.
